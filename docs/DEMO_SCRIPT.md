### Notes for filming

- The WISE 0855-0714 shot (0:10–0:20) is the one load-bearing demo beat —
  it's the required target with the largest, most visually obvious
  proper-motion jump of the five, so it reads clearly even at a glance in
  a 10-second clip. Have it pre-loaded (cached) before recording so there's
  no network wait on camera.
- If recording the live blink animation, set playback speed to the
  player's upper range so at least 2–3 full epoch cycles fit in the
  10-second window.
- Keep the crosshair visible in frame — it's what tells a first-time
  viewer where to look.

## 7-slide alternative (if a static deck is needed instead of/alongside video)

1. **Title** — Project name, tagline, team name, Barranquilla, Colombia,
   NASA Space Apps 2026, "Planet X and SPHEREx" challenge.
2. **The problem** — Moving/variable objects (candidate Planet X
   signatures, brown dwarfs, variable stars) hide in plain sight across
   repeated sky images; finding them has historically meant manually
   blinking photographic plates (Tombaugh, 1930) or WISE frames (Backyard
   Worlds today).
3. **The data** — SPHEREx: NASA's newest all-sky infrared survey, 102
   wavelength bands, resurveyed every ~6 months — a new, independent
   dataset perfectly suited to the same blink technique, with a built-in
   spectrum at every pixel that WISE never had.
4. **The tool** — Screenshot of the live UI: enter a name or coordinates,
   get a blink animation, a spectrum, a light curve, and a Gaia/AllWISE
   sky view, aligned and normalized automatically.
5. **Proof it works** — Side-by-side of two real cached epochs for a
   required target (e.g. Barnard's Star or WISE 0855-0714) showing the
   visible jump, plus the extracted spectrum plot.
6. **Why it matters for this challenge + LATAM** — Direct relevance (a
   real search tool for Planet X-type signatures), plus the
   accessibility angle: bilingual, low-bandwidth mode, southern-sky
   targets chosen for visibility from Colombia.
7. **Try it / credits** — Live URL (or QR code), GitHub link, NASA/ESA/CDS
   data credits, AI-assistance note.
